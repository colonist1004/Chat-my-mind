# 💬 Chat My Mind

성격·말투·세계관을 마음대로 정한 **나만의 AI 캐릭터**와 대화하는 채팅 앱입니다.
모바일과 PC 브라우저 어디서나 동작하고, 홈 화면에 앱처럼 설치(PWA)할 수 있습니다.
AI 는 Anthropic **Claude** API 를 사용합니다.

## 기능

| 기능 | 내용 |
|---|---|
| 캐릭터 만들기 | 이름, 사진/이모지, 한 줄 소개, 성격, 말투, 배경, 상황·세계관, 첫 메시지, 예시 대화, 태그 |
| 채팅 | 실시간 스트리밍 답변, `*행동*` 지문 표시, 답변 다시 생성, 메시지 수정·삭제, 생성 중 멈추기 |
| 대화 관리 | 캐릭터마다 여러 대화(새 대화 / 대화 목록), 대화별 **유저 노트**(캐릭터가 항상 기억할 내용) |
| 내 페르소나 | 내 이름과 설명을 정하면 캐릭터가 그에 맞게 반응. `{{user}}`, `{{char}}` 치환 지원 |
| 모델 설정 | Claude Opus 5.5(기본) / Sonnet 5.5 / Haiku 5.5, 사고 깊이, 답변 길이, 최대 토큰 |
| 공유·백업 | 캐릭터 JSON 내보내기/가져오기, 전체 백업/복원 |
| 화면 | PC: 왼쪽 캐릭터 목록 + 채팅 / 모바일: 한 화면씩, 다크 테마 |

데이터(캐릭터, 대화, API 키)는 모두 **사용하는 기기의 브라우저(IndexedDB)** 에만 저장됩니다.

## 사용 방법

1. [Claude Console](https://platform.claude.com/settings/keys) 에서 API 키를 발급받습니다.
2. 앱의 ⚙️ 설정에 키를 입력하고 저장합니다.
3. **＋ 새 캐릭터** 로 캐릭터를 만들거나, 처음 화면의 **예시 캐릭터 불러오기** 를 누릅니다.
4. 휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가** 로 앱처럼 쓸 수 있습니다.

## 개발

Node 20+ 필요.

```bash
npm install
npm run dev      # http://localhost:5173 (같은 와이파이의 휴대폰에서도 접속 가능)
npm run build    # dist/ 에 정적 파일 생성
```

`main` 브랜치에 푸시하면 GitHub Actions 가 GitHub Pages 로 배포합니다
(저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정).

## 구조

- `src/main.js` — 화면(홈, 캐릭터 편집, 채팅, 설정)과 라우팅
- `src/prompt.js` — 캐릭터 정보 → 시스템 프롬프트(롤플레이 규칙, 답변 길이)
- `src/ai.js` — Claude API 스트리밍 호출(`@anthropic-ai/sdk`), 오류 메시지
- `src/store.js` — IndexedDB 저장, 백업/복원
- `src/samples.js` — 예시 캐릭터
- `public/` — PWA 매니페스트, 서비스 워커, 아이콘

## 참고 / 다음 단계

- 지금은 각자 **본인 API 키**를 넣어 쓰는 방식이라 서버가 필요 없습니다.
  여러 사람에게 서비스하려면 키를 서버에 두는 백엔드(로그인, 사용량 제한, 결제)가 필요합니다.
- Opus 5.5 / Sonnet 5.5 는 안전 분류기가 요청을 거절하면 서버에서 다른 모델로 자동 재시도하도록
  (`fallbacks: "default"`) 설정되어 있습니다.
- 안드로이드 APK 가 필요하면 Capacitor 로 `dist/` 를 감싸면 됩니다.
